# Аргунский маршрут: от «Сердца Чечни» до «города мёртвых»

Интерактивный сайт-путеводитель по Чеченской Республике: 10 остановок из Грозного на юг — к древнему некрополю Цой-Педе.
Проект по ОРГ, НИУ ВШЭ. Команда: Рахман, Тихон, Влад, Миша.

**Сайт:** https://rohmanchiksuper-dotcom.github.io/putevoditel-chechnya/

## Как устроено

Статический сайт без сборки — открывается двойным кликом по `index.html`.

| Файл | Что внутри |
|---|---|
| `index.html` | страница: шапка, «Что такое Чечня», карта, монета, источники |
| `js/data.js` | все тексты и координаты 10 остановок (тексты правятся здесь) |
| `js/app.js` | карта и сборка карточек |
| `js/extras.js` | дополнительные эффекты |
| `css/style.css` | оформление |
| `vendor/` | Leaflet 1.9.4 (локально) |
| `images/` | фотографии (авторы и лицензии указаны на сайте) |

Подробности — в `README.txt`.

## Публикация

Каждый push в `main` автоматически публикует сайт на GitHub Pages (`.github/workflows/pages.yml`).
Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.
